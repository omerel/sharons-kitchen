# המטבח של שרון — אתר דמו אינטראקטיבי

## פתיחת הדמו

**הדרך המהירה:** פתחו את הקובץ `Sharon_Kitchen_Interactive_Demo.html` בדפדפן באמצעות לחיצה כפולה. ניתן גם להפעיל את `index.html` כאשר `styles.css` ו-`app.js` נמצאים לידו באותה תיקייה.

אין צורך בהתקנה, בחשבון שירות או בשרת. הדמו נשמר בזיכרון המקומי של הדפדפן (`localStorage`) — כלומר שינויים נשמרים באותו דפדפן ובאותו מחשב, אך אינם מסתנכרנים בין אנשים.

## מסלול מומלץ להדגמה לבעלי העסק

1. פתחו את **תצוגת לקוח** ובחרו `התפריט שלנו`.
2. בחרו מנה, משקל וכמות, והוסיפו לסל. שימו לב למינימום הזמנה בדמו, ₪80.
3. עברו לסיום הזמנה: פרטים, איסוף עצמי או משלוח (כשהופעל בממשק הניהול), חלון שעות וביט/העברה.
4. בצעו הזמנה. בעמוד מעקב ההזמנה לחצו על `סימנתי שביצעתי תשלום`.
5. עברו למעלה ל-**תצוגת מנהל**. בדקו את ההזמנה בטבלת ההזמנות ובמסך התשלומים.
6. אשרו ידנית את התשלום, שנו מצב הכנה ופתחו דוחות הכנה/אריזה.
7. בצעו ייצוא **Excel אמיתי (.xlsx)** או הדפיסו את הדוח.
8. עברו למסך **הגדרות והרשאות**, הפעילו את המתג של משלוחים ושמרו. חזרו ללקוח: אפשרות המשלוח הופיעה, עם מחיר קבוע וכתובת.
9. בצעו בקשת שינוי או ביטול מצד הלקוח, עברו למנהל, ואשרו/דחו. ראו את השפעת השינוי על הסכום ועל המכסות.
10. כדי להתחיל מחדש, לחצו על **איפוס הדמו** בפס העליון.

## מה כלול בדמו

- עמוד בית, אודות, תפריט, חיפוש, קטגוריות ופרטי מנות.
- מספר אפשרויות משקל למנה, כמות, הערות, מרכיבים, מידע תזונתי לדוגמה ומכסות.
- סל קניות, הזמנה כאורח, הדמיית Google, איסוף עצמי וחלונות אספקה.
- מתג הצגה/הסתרה של **משלוחים** ומחיר משלוח קבוע.
- הדמיית תשלום ביט/העברה, 24 שעות לתשלום, ביטול ידני בלבד.
- מסך מעקב, סימון תשלום ובקשת שינוי/ביטול.
- ממשק מנהל, ניהול מנות, מחזורים, מכסות, חלונות אספקה, הזמנות ותשלומים.
- קבלה ידנית של תשלום והחזר (ללא העברת כסף), חישוב יתרות והפרשי מחיר.
- דוחות הכנה — כולם/שולמו; דוחות אריזה — מרוכז/דף לכל הזמנה.
- הדפסה וייצוא Excel אמיתי (`.xlsx`).
- התמדה מקומית בדפדפן ואיפוס הדמו.

## גבולות הדמו — חשוב

**זהו אבטיפוס אינטראקטיבי לצורכי הצגה בלבד, לא מוצר ייצור.** אין Backend אמיתי, מסד נתונים, אימות Google, בקרת הרשאות, אחסון מאובטח, שליחת אימיילים, הודעות WhatsApp, סליקה, יצירת חשבוניות או אימות תשלומים. כפתורי הפעולה מדמים התנהגות ושומרים נתונים מקומית בלבד. אפילו מעבר לתצוגת מנהל הוא ללא סיסמה.

- התפריט, הלקוחות, הכתובת, הטלפון, התשלומים, התמונות והמחירים הם **נתוני דוגמה** בלבד.
- תמונות המחשה עשויות להיטען דרך האינטרנט; ללא אינטרנט יוצגו איורי אימוג׳י.
- המנגנון המדומה בודק מכסות, אבל אינו מספק טרנזקציות אטומיות לריבוי משתמשים. בגרסת ייצור חייבים לממש ב-PostgreSQL.
- ב-MVP האמיתי מתוכננות התראות אימייל; אוטומציית WhatsApp, דירוגים, מועדפים והזמנות חוזרות נדחו לגרסה 1.1.
- נתוני ארוחת סוף השבוע מתחדשים כאשר מאפסים את הדמו, לפי התאריך שבו נפתח הדפדפן.

## תכולת תיקיית הפרויקט

- `index.html` — דף HTML מקושר לקובצי CSS/JS.
- `styles.css` — עיצוב מותאם למחשב ולטלפון, כולל עברית RTL.
- `app.js` — התנהגות תצוגות הלקוח והמנהל, דוגמאות הנתונים ומנגנון ייצוא Excel.
- `preview-home.png`, `preview-admin.png` — צילומי מסך להמחשה.

להעברה לפיתוח Claude אפשר לצרף את תיקיית הדמו הזו לצד חבילת מסמכי האפיון שכבר נוצרה, ולבקש ממנו לשחזר את התנהגות המסכים על גבי Next.js/Supabase תוך החלפת כל הסימולציות בחיבורי שרת מאובטחים.
